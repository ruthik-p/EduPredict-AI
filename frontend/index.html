    Workflow

    How It Works

    The EduPredict AI pipeline takes raw academic data and transforms it into actionable insights in four steps.

    01
    📝

    Enter Academic Details

    Student enters academic information including attendance, study hours, assignment scores, internal marks, exam scores, and participation level.

    02
    🧠

    ML Analysis

    The trained supervised-learning models analyse the input. Both the classifier and regressor process the feature vector simultaneously.

    03
    🎯

    Performance Prediction

    Decision Tree models estimate the student's score and performance category (Excellent, Good, Average, or Needs Improvement) with confidence scores.

    04
    💡

    Personalised Guidance

    The system generates targeted recommendations based on the student's weaker areas, helping them focus efforts for maximum improvement.

    Project

    About EduPredict AI

    EduPredict AI demonstrates applied machine learning for educational analytics — built as part of the IBM SkillsBuild + AICTE 6-Week ML & Applied AI Internship. It uses supervised learning models trained on student academic data to deliver data-driven performance insights.

    🌳

    Decision Tree Classifier

    Predicts the student's performance category — Excellent, Good, Average, or Needs Improvement — along with classification confidence probabilities.

    📉

    Decision Tree Regressor

    Estimates the numerical performance score on a 0–100 scale, providing a precise quantitative measure of expected academic performance.

    🐍

    Python + scikit-learn

    The ML pipeline is developed in Python using scikit-learn for model training, evaluation, and serialisation with joblib.

    ⚗️

    Flask API

    A lightweight Flask REST API connects the trained ML models with the web interface, exposing a clean /predict endpoint.
